📱 Cara Pasang di Layar Utama iPhone

1. Buka Lewat Safari di iPhone

Unggah file HTML ini secara gratis (misalnya ke GitHub Pages, Netlify Drop, atau Tiiny.host) untuk mendapatkan link pribadi, lalu buka link tersebut di aplikasi Safari iPhone.

2. Tekan Tombol Share (Bagikan)

Ketuk ikon Share (kotak dengan panah ke atas ⬆️) di bagian bawah layar Safari.

3. Pilih "Add to Home Screen"

Gulir ke bawah lalu pilih Add to Home Screen (Tambahkan ke Layar Utama) → ketuk Add. Ikon 🐱 Ngeplot Duwek akan muncul di Home Screen dan terbuka layar penuh tanpa bilah alamat Safari!

💡 Catatan Penting iOS: Jangan membuka file .html langsung dari aplikasi Files iPhone karena pratinjau bawaan iOS membatasi penyimpanan otomatis. Gunakan link via Safari + tombol 💾 Backup secara berkala ya!
